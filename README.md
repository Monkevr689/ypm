## KushCraft (Minecraft Paper 26.3 plugin)

The drug economy for an anarchy PvP server: grow, cook and deal, a 12-rank ladder gated by money and playtime, rank-limited workers, cartels, season resets with verified backups. Everything is in a SQLite database with a full transaction log, and KushCraft is the server's Vault economy. Custom textures, plants, machines, strains and effects, all in one jar. See [`kushcraft/README.md`](kushcraft/README.md).
