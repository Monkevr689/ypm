# ypm

## SMPSuite + KushCraft (Minecraft Paper 26.3 plugins)

A survival-first SMP setup, two jars:

* **[SMPSuite](smpsuite/README.md)** – the main progression: skills (Mining, Farming, Fishing, Foraging,
  Excavation, Combat, Vitality) with small hard-capped bonuses, jobs pay and skill abilities (Haste Pulse,
  Tree Feller…), the eight **Bliss gems**, opt-in **teams** and **Simple Voice Chat** groups.
  Download: [`smpsuite/release/SMPSuite-1.0.0.jar`](smpsuite/release/SMPSuite-1.0.0.jar)
* **[KushCraft](kushcraft/README.md)** – a grow / lab / dealer side activity with custom textures. In add-on
  mode (default since 8.1) players unlock it on purpose, it stays away from spawn and pays a fraction of
  what skills pay. Download: [`kushcraft/release/KushCraft-8.1.0.jar`](kushcraft/release/KushCraft-8.1.0.jar)

Voice chat also needs the [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) server plugin,
and the mod on each player's client.
